## 2. Corpus VIN — le nouveau fichier n'apportait rien (`0f1df67`)

- **`scripts/extract-corpus.py` créé** : fusionne les sources **`.xls` (xlrd) et `.xlsx` (openpyxl)**,
  déduplique par VIN, produit `echantillon.csv`.
- **Résultat mesuré, dit franchement** : `Export VIN du 01_01_2010 au 31_12_2020.xls` (**32 737 lignes**)

## 3. Splash sur Affichage et Pointage (`9d6b387`, `9e56328`)

> *« peux-tu ajouter à nos deux autres petites applications […] notre petite image flash qui vient
> avant le démarrage de l'application ? »*

### ⚠️ Première version rejetée — violation de la règle 16 (copie fidèle)

Retour de l'utilisateur, précis :
> *« ce n'est pas ce que nous avons fait sur l'application principale. Les images flash, tu as mis un
> gros arrière-plan, un carré derrière, et ce n'est pas la même dimension […]. Vérifie ce que nous
> avons exactement fait sur l'application principale et compare. »*

**Il avait raison** : une adaptation avait été livrée à la place d'une copie.

| | Première version ❌ | Corrigée ✅ |
|---|---|---|
| Fenêtre | grande (58 % de l'écran) | **500×320 pendant le flash, puis s'agrandit** |
| Scène | petite carte arrondie flottante sur fond sombre | **remplit toute la fenêtre, bord à bord** |

**Leçon (re)confirmée : « copier » veut dire lire l'existant et le reproduire à l'identique, pas
l'adapter.** C'est exactement la règle 16.

Contenu du splash : image `car-lowpoly.png`, réseau technique SVG, circuit, radar, ligne de scan,
titre TCIT, barre de progression aux couleurs du drapeau togolais. `SPLASH_DURATION = 2200`,
keyframes dédiées + `prefers-reduced-motion`. Portail d'état dans `main.tsx` (composant `Racine`).
Sur Pointage, le portail **préserve la fenêtre d'aperçu** (`location.hash.includes('apercu')`).

## 4. Installeurs de test — étude de faisabilité (fin de session)

> *« est-il possible de faire un fichier install de tests de nos trois applications électron pour que
> je puisse l'envoyer à un collaborateur qui va […] tester pour voir s'il y a des améliorations ou des
> choses qui ne fonctionnent pas bien pour que nous puissions finaliser ce projet ? »*

**État des lieux donné franchement** : les 3 apps ont **déjà electron-builder configuré** (cible NSIS,
script `npm run package`) — on ne part pas de zéro. **Mais un `npm run package` brut ne suffira pas**,
le piège principal étant **Prisma/SQLite** dans l'app principale.

**Choix de l'utilisateur** : tester **aussi le flux inter-apps**, **3 installeurs NSIS dans un ZIP**,
**icône TCIT générée**.

**Faisabilité du flux inter-apps confirmée sur une seule machine** :
- **TCIT → Pointage : automatique** — les deux lisent/écrivent le même fichier
  `C:\ProgramData\TCIT\stca-m.json` (chemin identique dans les deux apps).
- **Guichet → Affichage** : l'app principale émet sur `ws://192.168.0.25:8000` par défaut → il suffira
  de pré-régler l'IP de l'afficheur sur `127.0.0.1` pour le test.
