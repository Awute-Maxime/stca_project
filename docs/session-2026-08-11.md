## Architecture retenue (option A)

**Source unique partagée : le fichier `%PROGRAMDATA%\TCIT\branding.json`** — même principe que
`stca-m.json` — lu par les 3 apps, **appliqué localement**. Sections :

- `identite` : nom, sigle, slogan, logo (base64), coordonnées
- `apparence` : thème (clair / sombre / auto), couleur primaire, couleur d'accent
- `documents` : logo, cachet, en-tête, pied de page, mentions légales, n° d'agrément, devise, RIB

Précision d'architecture : **l'app principale n'utilise pas `tcit-ui`** → elle a son **propre** module
branding ; `tcit-ui` servira Affichage et Pointage (plan C). **Seul le fichier est partagé.**

Périmètre V1 : (1) mode sombre, (2) identité/marque, (3) documents imprimés.
Métier (tarifs, numérotation) et Système → V2.

**Limite dite franchement à l'utilisateur** : l'icône du `.exe` reste figée au build ; le logo
personnalisé s'applique à l'app, au splash et aux documents, pas à l'icône du fichier.

## ⚠️ Piège de test découvert ce jour

Poser `data-theme=dark` via CDP ne bascule **que les variables CSS** — **Ant Design reste clair**, car
il est piloté par `useBranding()` / `branding.json`. Pour une vérification visuelle fidèle, il faut
**écrire un vrai `branding.json` sombre** puis recharger. Sinon on croit à tort que les tables AntD
sont restées blanches.

## Méthode rodée pour convertir un écran

Lire le fichier → remplacer les couleurs codées en dur par les `--tc-*` (palette locale `C`,
sous-header beige → `--tc-subheader-*`, tables → `--tc-thead-*` / `--tc-td-line`, `#fff` →
`--tc-card`, `#F8FAFF` → `--tc-section`, `#475569` → `--tc-label`, `#64748B` → `--tc-muted`) →
**garder les couleurs métier** → `npx tsc --noEmit -p tsconfig.web.json` → commit.
**Règle sacrée : chaque variable claire = la valeur d'origine exacte.**
